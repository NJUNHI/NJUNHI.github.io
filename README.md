# 南赫Wiki

> 一份由南赫同学一起补完的学习、科研与生活地图。

南赫Wiki站是面向南赫同学的民间 Wiki，其由学生自发组建，不代表官方观点。

## 当前栏目

- 学院概览：学院简介、办学优势、合作历程、师资队伍、管理队伍与联系方式
- 学生手册与经验：手册导览、常用信息、培养体系、学习建议、生涯规划、交换学习与校园生活
- 课程资料：课程笔记、作业与习题、按课程查找
- 共建指南：投稿方式、内容边界与更新原则

还有很多未补充内容欢迎大家填写！

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm ci
npm run dev
```

完成修改后运行：

```bash
npm run check
```

导出 GitHub Pages 静态站点：

```bash
npm run build:pages
```

网站地址：[https://njunhi.github.io/](https://njunhi.github.io/)

## 投稿与发布

请从 `main` 新建分支，在分支中上传文件或修改内容，再提交 Pull Request。不要直接修改 `gh-pages`；它只保存网站发布结果。

Pull Request 会自动检查代码、全部页面和站内链接。审核合并到 `main` 后，GitHub Actions 会自动构建并发布网站，不需要维护者再手动同步 `gh-pages`。

网页直接使用的图片和小型 PDF 放在 `public/` 下。上传前请压缩文件，并确认来源、版权、适用学年和隐私信息。

## 内容来源与原则

学院基础信息根据[学院官方网站](https://nh.nju.edu.cn/)公开页面重新整理。所有信息以官方网站为准！
